= Terminology

- add: Displays the form component for creating a new object (e.g., involved person). A new object is added to the store.
- create: Updates an added object in the store if all required fields are filled in. Also calls the API to create the object.
- edit: Displays the form component for editing an existing object (e.g., involved person).
- update: Updates an edited object in the store if all required fields are filled in. Also calls the API to update the object.
- delete: Removes a selected object from the store. Also calls the API to delete the object.
